Verilator Homepage

Installation

Linux

Arch Linux:

sudo pacman -S verilator

Debian/Ubuntu:

sudo apt-get install verilator

Windows

Install using WSL or compile with MinGW/Cygwin

Compile and Install

git clone https://github.com/verilator/verilator
autoconf
./configure
make -j `nproc`
sudo make install

Common Options Explained

  • --cc Generate C library
  • --sc Generate SystemC
  • --exe Create a Makefile including test programs to generate simulation executables
  • --build Automatically invoke the compiler to build the final executable
  • --binary Generate binary file
  • --trace Enable waveform generation during execution
  • --trace-fst Generate waveform in FST format

Project Setup

Create a project directory:

mkdir vtest ; cd vtest

Create folders for Verilog and C++ test programs:

mkdir csrc vsrc

Write the Verilog Module

vim vsrc/our_OnOff.v

module our_OnOff(
    input a,
    input b,
    output f
);

assign f = a^b;

endmodule

This example creates a module our_OnOff, with inputs a and b, and output f as the XOR of a and b.

Write the Test Program

vim csrc/main.c

#include <stdio.h>
#include <stdlib.h>
#include <assert.h>
#include "Vour_OnOff.h"
#include "verilated_vcd_c.h"
 
vluint64_t main_time = 0;

int flag = 100;
 
double sc_time_stamp()
 {
     return main_time;
 }
 
int main(int argc,char **argv)
{
     Verilated::commandArgs(argc,argv);
     Verilated::traceEverOn(true); //导出vcd波形
 
     VerilatedVcdC* tfp = new VerilatedVcdC();
 
     Vour_OnOff *top = new Vour_OnOff("top");
     top->trace(tfp, 0);
     tfp->open("wave.vcd"); //打开vcd
 
      while(!sc_time_stamp() < 20 && !Verilated::gotFinish() && flag)
     {                                                                                                                                                                                                            
     int a = rand() & 1;
     int b = rand() & 1;
     top->a = a;
     top->b = b;
     top->eval();
     printf("a = %d, b = %d, f = %d\n",a,b, top->f);
     tfp->dump(main_time);
     main_time++;
     flag--;
     }
     top->final();
     tfp->close();
     delete top;
     return 0;
}

The test program generates random inputs a and b, and exports VCD waveform data.

Makefile

all:
 @verilator --trace -Wall --cc vsrc/our_OnOff.v --exe csrc/main.c 
 @make -C obj_dir -f Vour_OnOff.mk Vour_OnOff

sim: all
 @./obj_dir/Vour_OnOff
 @gtkwave wave.vcd

clean:
 @rm -rf ./obj_dir/
 @rm wave.vcd

all target: Uses Verilator to generate C library and Makefile (Vour_OnOff.mk), and compiles the code with make.

sim target: Runs the compiled executable and opens waveform with GTKWave after all.

clean: Removes obj_dir and wave.vcd.
